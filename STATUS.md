## ⚠️ Ограничения

### 1. Производительность для малых N
- FMM медленнее direct для N < 10000
- OpenMP overhead для малых задач
- Первая итерация медленнее из-за инициализации

### 2. Точность для высоких порядков
- Для p > 6 используются аппроксимированные формулы
- Целевая точность 10^-10 достигается только при p ≥ 8-10
- High-order derivatives требуют более точной реализации

### 3. M2L operator
- Текущая реализация упрощенная (прямое вычисление вместо трансляции)
- Не полностью оптимальна для O(N) в теории
- Работает правильно, но может быть улучшена

## 🔄 Возможные улучшения

### Производительность
1. **Убрать OpenMP для N < threshold**
   - Автоматически определять когда использовать параллелизацию
   - Уменьшить overhead для малых задач

2. **Оптимизировать вычисление производных**
   - Предвычислить таблицы для низких порядков
   - Использовать более эффективные формулы для высоких порядков
   - Кэшировать часто используемые значения

3. **Улучшить memory layout**
   - Structure of Arrays вместо Array of Structures
   - Лучший cache locality
   - SIMD vectorization

### Точность
1. **Полная реализация M2L**
   - Правильные трансляционные операторы
   - Taylor expansion для M2L
   - Достичь точности 10^-10 для всех p

2. **Адаптивный near-range**
   - Динамически выбирать near_range based на p
   - Баланс точности и скорости

3. **Высшие порядки**
   - Точные формулы для p > 6
   - Рекурсивные соотношения для производных

### Функциональность
1. **Адаптивная сетка (Octree)**
   - Автоматическое разбиение для неоднородных распределений
   - Лучшее масштабирование для кластеризованных систем

2. **Периодические граничные условия**
   - Эвальд суммирование для периодических систем
   - Важно для сверхпроводников

3. **Другие потенциалы**
   - Yukawa (экранированный Кулон)
   - Lennard-Jones
   - Custom potentials

4. **3D версия**
   - Обобщение на полный 3D случай
   - Сферические гармоники для 3D
