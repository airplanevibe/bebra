===============================================================================
6. ИСПОЛЬЗОВАНИЕ В PYTHON КОДЕ / PYTHON CODE USAGE
===============================================================================

import numpy as np
from multipole_2d_final import MultipoleExpansion2D, compute_potential_direct

# Параметры
p_max = 25
N_sources = 100

# Создать источники в круге
angles = np.random.uniform(0, 2*np.pi, N_sources)
radii = np.random.uniform(0, 1.0, N_sources)

sources = np.zeros((N_sources, 3))
sources[:, 0] = radii * np.cos(angles)
sources[:, 1] = radii * np.sin(angles)
sources[:, 2] = 0.0  # 2D: z = 0

charges = np.random.uniform(-1.0, 1.0, N_sources)

# Точки оценки (вне области источников!)
eval_points = np.array([[3.0, 0.0, 0.0],
                        [0.0, 3.0, 0.0],
                        [2.5, 2.5, 0.0]])

# Вычислить мультипольное разложение
multipole = MultipoleExpansion2D(p_max)
center = np.array([0.0, 0.0, 0.0])

rel_sources, moments = multipole.compute_multipole_coefficients(
    sources, charges, center
)

potentials = multipole.evaluate_potential_batch(
    rel_sources, moments, eval_points, center
)

print("Потенциалы:", potentials)

===============================================================================
7. РЕКОМЕНДАЦИИ ПО ПАРАМЕТРАМ / PARAMETER RECOMMENDATIONS
===============================================================================

Для машинной точности (~10^-15):
  --p-max 28-32
  --eval-radius / source-radius >= 2.5

Для высокой точности (~10^-10):
  --p-max 22-26
  --eval-radius / source-radius >= 2.0

Для хорошей точности (~10^-7):
  --p-max 15-20
  --eval-radius / source-radius >= 1.5

Для быстрых вычислений (~10^-4):
  --p-max 8-12
  --eval-radius / source-radius >= 1.2

===============================================================================
8. ВАЖНЫЕ ОГРАНИЧЕНИЯ / IMPORTANT LIMITATIONS
===============================================================================

1. Точки оценки ДОЛЖНЫ быть вне области источников
   (eval_radius > source_radius)

2. Все точки должны быть в плоскости z=0 для 2D режима

3. Текущая реализация: O(N*M*p) - не полная FMM
   Для O((N+M)*p^2) нужна иерархическая структура

4. При больших p_max (>30) возможна потеря численной стабильности
