# Grid-Based Fast Multipole Method (FMM) for 2D Superconductor Simulations

Высокоточная и эффективная реализация FMM для двумерного кулоновского потенциала с настраиваемым порядком разложения.

## Особенности

- **Настраиваемый порядок разложения**: параметр `p` можно задавать от 2 до 10+
- **2D оптимизация**: использует декартовы мультипольные разложения для плоскости z=0
- **Высокая точность**: RMS ошибка < 10^-10 при высоких порядках (p≥8)
- **Высокая скорость**: O(N) сложность вместо O(N²)
- **Легко заменяемый потенциал**: модульная архитектура для различных потенциалов
- **Проверка точности**: сравнение с прямым расчетом для валидации

## Математическая основа

### 2D Картезианское мультипольное разложение

Для 2D кулоновского потенциала φ(r) = q/r при z=0 используется разложение:

**P2M (Particle-to-Multipole)**:
```
M_kl = Σ_i q_i * (x_i - x_c)^k * (y_i - y_c)^l
```

**M2L (Multipole-to-Local)**:
```
L_jm = Σ_kl M_kl * T_jm_kl(dx, dy)
```

где T - оператор трансляции, включающий производные 1/r.

**L2P (Local-to-Particle)**:
```
φ(x,y) = Σ_kl L_kl * (x-x_c)^k * (y-y_c)^l / (k! * l!)
F = -∇φ
```

### Порядок разложения

- **p = 2**: Монополь + диполь + квадруполь (быстро, низкая точность)
- **p = 4**: До октуполя (баланс скорости и точности)
- **p = 6**: Рекомендуется для большинства применений
- **p = 8**: Высокая точность (RMS ~ 10^-9)
- **p = 10**: Очень высокая точность (RMS ~ 10^-10+)

## Сборка

### Требования

- Fortran компилятор: gfortran ≥ 7.0 или ifort ≥ 18.0
- OpenMP (опционально, для параллелизации)
- Make

### Компиляция

```bash
# Компиляция с gfortran (по умолчанию)
make

# Компиляция с Intel Fortran
make FC=ifort

# Отладочная сборка
make debug

# Очистка
make clean
```

## Использование

### Базовый запуск

```bash
make run
```

### Настройка параметров

Отредактируйте `src/main.f90`:

```fortran
! Параметры симуляции
N = 5000              ! Число частиц
dt = 0.001_dp         ! Шаг по времени
Lbox = 1.0_dp         ! Размер области
nsteps = 3            ! Число шагов MD

! Параметры FMM
p_order = 6           ! Порядок разложения (2, 4, 6, 8, 10)
ngrid = 40            ! Размер сетки (ngrid × ngrid ячеек)
```

### Тестирование точности

Запустите автоматическое тестирование с различными параметрами:

```bash
./test_accuracy.sh
```

Это протестирует:
- Различные порядки разложения (p = 2, 4, 6, 8, 10)
- Различные размеры сетки (20×20 до 60×60)
- Различное число частиц (1000 до 10000)

Результаты сохраняются в `test_results/`.

## Выходные данные

Программа выводит:

1. **Параметры симуляции**: N, p, размер сетки
2. **Время выполнения**:
   - FMM время
   - Время прямого расчета (O(N²))
   - Ускорение (speedup)
3. **Точность**:
   - Сравнение сил (первые 10 частиц)
   - Сравнение потенциалов
   - Максимальная абсолютная ошибка
   - RMS ошибка
   - Относительная ошибка
4. **Статистика производительности**:
   - Сложность на частицу
   - Сложность на пару

## Оптимизация производительности

### Выбор параметров

1. **Порядок разложения (p)**:
   - Увеличение p → выше точность, но медленнее
   - Для точности 10^-8: используйте p ≥ 6
   - Для точности 10^-10: используйте p ≥ 8

2. **Размер сетки (ngrid)**:
   - Оптимально: 10-30 частиц на ячейку
   - Малый ngrid → больше прямых расчетов
   - Большой ngrid → больше M2L операций
   - Рекомендуется: ngrid ≈ √(N/20)

3. **Near-range**:
   - Автоматически устанавливается: max(2, √p)
   - Большой near-range → выше точность, но медленнее

2. Добавьте соответствующую функцию силы
3. В `main.f90` замените вызов `set_coulomb_potential()`
