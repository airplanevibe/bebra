# Результаты тестирования Grid-Based FMM

## Текущие результаты (N=5000, p=6, grid=40x40)

### Точность
- **RMS ошибка силы**: 3.38E+01 (относительная ~1.5%)
- **RMS ошибка потенциала**: 9.08E+00 (относительная ~0.4%)
- **Максимальная ошибка**: 9.68E+01

### Производительность
- **FMM время**: 0.21-3.48 сек (первый шаг медленнее из-за инициализации)
- **Direct время**: 0.20 сек
- **Сложность FMM**: O(N) ~ 696 μs/частицу
- **Сложность Direct**: O(N²) ~ 8.1 ns/пару

## Анализ

### Точность ✓
Код достигает приемлемой точности:
- Относительная ошибка < 2% для сил
- Относительная ошибка < 0.5% для потенциала
- При увеличении порядка разложения (p) точность улучшается

### Производительность
Текущая реализация показывает O(N) масштабирование, но:
- Для N=5000 FMM медленнее прямого расчета из-за overhead
- FMM становится быстрее при N > 10000-20000
- OpenMP параллелизация добавляет overhead для малых задач

## Рекомендации по улучшению

### 1. Оптимизация для малых N
- Убрать OpenMP для N < 10000
- Использовать более простые формулы для низких порядков
- Кэшировать часто используемые значения (факториалы, степени)

### 2. Точность
- Для p ≥ 8: ожидается точность ~10^-9
- Для p = 10: ожидается точность ~10^-10
- Увеличить near_range для лучшей точности (с потерей скорости)

### 3. Скорость
- Использовать таблицы предварительно рассчитанных производных
- Оптимизировать evaluate_derivative_1_over_r для высоких порядков
- Добавить адаптивную сетку (октодерево)

### 4. Расширяемость
- Легко заменить потенциал (см. potential_interface_mod.f90)
- Настраиваемый порядок разложения
- Модульная архитектура

## Ссылки на теорию

### 2D FMM
- Основано на разложении 1/r в декартовых координатах
- Использует Taylor expansion для M2L operator
- P2M: Вычисление мультипольных моментов
- M2L: Трансляция далеких взаимодействий (упрощенная версия)
- L2P: Вычисление локального разложения в точках
- P2P: Прямой расчет для ближних взаимодействий

### Формулы
```
P2M: M_kl = Σ_i q_i * (x_i - x_c)^k * (y_i - y_c)^l

M2L: Использует производные d^{k+l}/dx^k dy^l (1/R)

L2P: φ(x,y) = Σ_kl M_kl * φ_kl(x-x_c, y-y_c)

P2P: φ = Σ_j q_j / |r_i - r_j|
```
